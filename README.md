# The Intern Finds It

A tiny Node/TypeScript program for the make.fun bounty "Fortune Cookie for an AI Agent". It writes one funny fortune cookie message for an AI agent to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 140 characters.

Entry line:

> Your next bug will be found by the intern, the fix will take one line, and the meeting about it will take two hours.

Run it with: `node main.ts`
